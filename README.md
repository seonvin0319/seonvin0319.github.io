# Seonvin Cho — GitHub Pages

Static academic homepage migrated from the public Google Sites portfolio.

## Publish

1. Create a public repository named `seonvin0319.github.io` in the `seonvin0319` account.
2. Upload the contents of this folder to the repository root and commit to `main`.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The website will be available at `https://seonvin0319.github.io/` after GitHub finishes deployment.

All document and image links use local files under `assets/`, so the site does not depend on Google Sites after publication.
